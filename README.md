# DryRock(岩コンディション予報)

クライミングのエリア選定用に、週末や指定日の天気からコンディションを予測・評価する Web アプリです。`index.html` 1ファイルで動き、ビルドは要りません。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作成します(例:`climbing-condition`)。Public にしてください。無料プランの Pages は Public リポジトリが対象です。
2. `index.html` をアップロードします(「Add file」→「Upload files」→ コミット)。
3. 「Settings」→「Pages」→「Build and deployment」で、Source に「Deploy from a branch」、Branch に `main` / `(root)` を選んで「Save」を押します。
4. 1〜2分ほどで `https://<ユーザー名>.github.io/climbing-condition/` が開けるようになります。
5. iPhone の Safari で開き、共有メニューの「ホーム画面に追加」を選ぶとアプリのように使えます。

## 使い方

- **アクティビティ**:外岩ボルダー/外岩ルート/マルチピッチ/沢登り/アルパイン。選んだアクティビティに合わせて、活動時間帯・適温・重みを切り替えて評価します。
- **日付**:直近の土日は自動で表示されます。「今日」「明日」やカレンダーから、16日先までの日付を追加できます。
- **ランキング / 比較表**:エリアごとのスコア(0–100点・◎○△×)と、その理由を表示します。カードやセルをタップすると、時間別のチャートと岩の濡れ量の推移を見られます。
- **エリア**:追加・編集・削除ができます。地名検索や Google マップの座標の貼り付けで場所を入れられ、岩質・向き・樹林度で乾きやすさを補正します。設定はブラウザに保存されるので、別の端末で使うときは「バックアップ / 復元」で引き継いでください。

## 評価ロジック(概要)

| 要素 | 内容 |
|---|---|
| 雷・降水 | 活動時間帯の最大降水確率と降水量。雷は天気コード95以上、またはCAPEと降水確率の組み合わせで判定。雷リスクが高い日は20点が上限 |
| 岩の乾き | 3日前からの降水を「濡れ量」として1時間ごとに積算し、蒸発散量(ET0)・日射・風で減らします。岩質・向き・樹林度で乾く速さを補正。濡れている日は乾き具合に応じて上限をかけます |
| 増水(沢) | 先行降水を24時間の時定数で減衰させた積算値 |
| フリクション | 活動時間帯の気温(アクティビティごとの適温帯)、湿度、気温と露点の差(結露) |
| 風 | 最大瞬間風速。上限はアクティビティごとに設定 |

各アクティビティの閾値や重みは、`index.html` 冒頭の `ACTIVITIES` / `ROCKS` / `ASPECTS` / `CANOPY` で調整できます。

データ:[Open-Meteo](https://open-meteo.com/)(CC BY 4.0、APIキー不要)。スコアはあくまで推定です。現地の状況と気象庁の最新情報もあわせて確認してください。
